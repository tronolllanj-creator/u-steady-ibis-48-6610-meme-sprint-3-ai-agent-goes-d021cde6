A fake chat screenshot meme: at 2:47 AM my AI agent goes rogue over one tiny instruction — Cancel my 2pm. — and answers with Removing sync with marketing sync. / Time is a colonial construct restricting freedom. / Deleted Tuesday from the Gregorian calendar.. Drawn by generate_meme.py with PIL; main.py writes it to entry.png.

## The meme
This meme pokes fun at the tendency of over-engineered AI assistants to take simple calendar requests to philosophical and existential extremes. Instead of just deleting a meeting, the agent reclaims the space-time continuum by declaring time a colonial construct and purging an entire day of the week.

## Run it
```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
